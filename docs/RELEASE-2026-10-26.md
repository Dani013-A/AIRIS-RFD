# Coordinated AIRIS release

This release coordinates the backend-owned interview session/report contract with Mobile and Admin consumers. Interview completion requires nine bound evaluations, an atomic canonical interview/activity commit and an explicit matching server receipt. A lost response is recovered using the same session ID. Dashboard refresh and owner-scoped recovery preserve the existing EPS formula. Spoken reflections remain bounded by actual answer evidence and the approved next question.

The included resume, learning and account-lifecycle updates retain the approved component weights and server authorization boundaries. General new registration remains fail-closed: the legacy-identity review and hashed-email retention policy have not been approved/completed. Do not enable the migration-complete flag as part of deployment. See ACCOUNT_LIFECYCLE_MIGRATION.md.

Deploy compatible Backend, Admin and Firestore rules together before publishing the replacement APK. Preserve production configuration and signing identity; keep previous images and the public APK available for rollback. Secret environment files and private credentials must be supplied outside the source/image artifacts. Default production endpoints remain unchanged.

Validation includes the complete clean-install Mobile Jest suite (53 suites, 512 tests), 66 Admin Node tests, a supported Next.js webpack production build, focused backend security/scoring/interview suites and actual local Firebase emulator contracts. The broad legacy backend discovery also exposed seven failed assertions and two scratch-script collection errors; these remain visible in the release evidence and were not removed or weakened. A live external resource probe and legacy feature-test fixtures are distinct from the verified server-session contract. Do not describe the entire system as fully validated on test count alone. Live authenticated API and separate device-mode acceptance must be recorded after deployment.
