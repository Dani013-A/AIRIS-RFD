## Download integrity and boundaries

The downloader resolves the packaged Expo asset, copies it to the app's dedicated resume-templates directory, verifies the file checksum, and invokes Android sharing with application/pdf. A mismatch is deleted and never shared. MD5 is used only for Expo FileSystem's supported local copy-integrity check; source provenance is recorded and tested with SHA-256. Missing storage, missing files and unavailable sharing have explicit outcomes. No private resume, profile data or research evidence is used to generate these resources.

Onboarding opens the same official resource screen. Format-warning recovery copy points to those resources without asserting that a generated AIRIS document is the official T.I.P. template. Resume acceptance, scoring formulas, authentication, interview behavior and the fail-closed registration gate are unchanged.
